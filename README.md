# Islamic Finance & Investing Research

Knowledge base untuk mempelajari uang, bisnis, perdagangan, saham, investasi, trading, risiko, serta prinsip keuangan Islam secara terstruktur.

## Tujuan

Repository ini bukan sekadar kumpulan cara mencari keuntungan. Tujuannya adalah memahami:

- apa yang sebenarnya dibeli atau diperdagangkan;
- bagaimana bisnis menciptakan nilai;
- dari mana keuntungan investor/trader berasal;
- risiko apa yang ditanggung;
- bagaimana pasar menentukan harga;
- bagaimana keputusan finansial dibuat secara rasional;
- bagaimana prinsip Islam seperti halal, riba, gharar, maysir, amanah, kejujuran, dan kejelasan akad diterapkan.

## Prinsip belajar

> Jangan mengejar uang sebelum memahami uang.

Pertanyaan dasar yang selalu digunakan:

1. Apa yang sebenarnya saya beli?
2. Bagaimana aset/bisnis tersebut menghasilkan nilai?
3. Dari mana keuntungan saya berasal?
4. Apa yang dapat membuat saya rugi?
5. Apa biaya dan risikonya?
6. Bagaimana mekanisme transaksinya?
7. Apakah kepemilikan dan akadnya jelas?
8. Apakah terdapat unsur riba, gharar yang dilarang, maysir, penipuan, atau kezaliman?
9. Apakah keputusan dibuat berdasarkan bukti dan analisis, bukan sekadar rumor?

## Roadmap

### Level 1 — Fondasi ekonomi
Uang → nilai → aset → liabilitas → modal → bisnis → pendapatan → biaya → laba → arus kas.

### Level 2 — Saham
Saham → perusahaan publik → bursa → IPO → bid/offer → order → kapitalisasi pasar → dividen → EPS.

### Level 3 — Investasi
Analisis fundamental → kualitas bisnis → laporan keuangan → valuasi → P/E → P/B → ROE → utang → free cash flow → margin of safety.

### Level 4 — Trading
Market structure → candlestick → trend → support/resistance → volume → probabilitas → risk/reward → stop loss → position sizing → expectancy → psikologi.

### Level 5 — Keuangan Islam
Jual beli → kerelaan → amanah → riba → gharar → maysir → penipuan/tadlis → akad → kepemilikan → saham syariah → mekanisme transaksi.

### Level 6 — Filosofi dan realitas
Filosofi uang → kekayaan sebagai amanah → konsumsi vs investasi → risiko → ketidakpastian → perbedaan harga dan nilai → disiplin → pengambilan keputusan.
